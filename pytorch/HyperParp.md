# Hyperparameter

1. epochs
- 학습의 사이클의 횟수, 학습을 몇번 할 것인가

2. batch-size
- 총 이미지를 나눴을 때 이미지 수 / 총이미지/n

3. image-size
- 입력이미지 크기

4. lr (learning rate)
- 학습률, 오차를 줄이는 크기

5. weight-decay
- AdamW가 가중치 크기를 억제하는 강도
- 높이면 규제가 강해지며 학습을 방해할 수 있음

6. background-weight
- 배경손실, 배경을 사람으로 잘못 판단한 오차를 존체 솔실에 반영하는 값
- 높이면 배경 오검출을 줄임, 사람의 점수도 낮아질 수 있음

7. box-weight
- 전체 손실에서 박스 위치, 크기 오차에 주는 가중치
- 높이면 박스를 정확하게 맞추는 오차를 더 중요하게 반영

8. score
- 사람 후보를 남길 최소 예측 점수
- 높이면 박스가 줄어들지만 사람을 더 놓칠 수 있음

9. nms-iou
- 예측끼리 중복 박스를 제거하는 겹침 기준
- 높이면 더 많이 겹쳐야 제거하므로, 박스가 더 많이 남을 수 있음

10. match-iou
- 예측과 정답이 일치했다고 인정할 겹침 기준
- 박스 위치가 더 정확해야 정답으로 인정

11. patience
- 조기 종료하는 옵션, 학습을 진행 중 n 에포크 진행 중 학습이 진행되지 않으면 조기 종료함
- 0이면 조기종료 없음, n - 학습중 학습이 진행되지 않을 때 종료할 count 순

12. monitor
- 평가 지표
- f1, val_loss

13. limit
14. augment
15. cpu
